## 1. 商业定位

**一句话定位**
> Global machine technology. Local engineering and service.
> 全球成熟的设备技术 + 本地化的工程、制造与服务。从概念设计到售后，由同一个团队负责。

**Verbindtech 实际在做的四类业务**（来自 PDF、原网站和博客）
1. **交钥匙生产线**：设计、制造、安装、调试，设计参照 cGMP 标准（例如茶粉生产线）。
2. **非标设备（SPM）**：自动化、检测、装配工站，以及工装夹具（汽车、制药、快消行业）。
3. **标准设备供应**：80 多种加工、灌装、包装、检测设备，由 6 家技术合作伙伴供货，本地完成集成。
4. **制造与维保**：不锈钢和非不锈钢制造、精密零件、老旧设备改造（Manesty、Glatt、Diosna、Bausch+Ströbel 等品牌），以及预测性维护（TPM）、故障维修和厂务维护。

**差异化：和三类竞争对手比**

| 对手 | 对方优势 | Verbindtech 的胜点 |
| --- | --- | --- |
| 欧洲 / 日本大厂（Syntegon、GEA、IMA 等） | 品牌、技术 | 成本、交期、本地响应速度、愿意做定制 |
| 纯进口贸易商 | 价格 | 工程设计能力、系统集成、本地制造、对结果负责的售后 |
| 本地小作坊 | 价格、灵活 | cGMP 经验、一线品牌客户背书、全球合作伙伴、完整的项目流程 |

**可以公开的证据**（都来自现有资料）
- 2008 年起步，集团历经 TJM、TEP、MCT、TWU、AGRU，2020 年成立 Verbindtech。
- 25 家以上客户：Kalbe、Kimia Farma、Bio Farma、Novartis、P&G、L'Oréal、AISIN、KYB 等。
- 工厂位于 Jababeka（芝卡朗），服务覆盖整个爪哇岛，客户分布在爪哇、苏门答腊、加里曼丹。
- 自产设备提供 1 年机械和电气质保；售后团队由服务工程师、设计工程师和技工组成。
- 设备发货前，在芝卡朗工厂和客户一起试机。定制设备的生产周期一般为 1 到 2 个月。
- 参加 ALLPACK Indonesia 2026 展会，展位 D104。

## 2. 对标：行业头部网站的共同做法

对标对象：Syntegon、GEA、IMA、Krones（加工和包装设备），以及 ATS Automation（非标自动化）。

| 头部网站的做法 | 新网站对应的设计 |
| --- | --- |
| 导航按「行业 × 解决方案 × 服务」三条线组织，用大菜单展开 | 一级导航：Industries / Solutions / Services / Projects / Company，带大菜单 |
| 把「全生命周期服务」当成独立的业务线（安装、维保、改造、备件） | 单独做 Services 页面，首页有服务区块和 WhatsApp 报修入口 |
| 每个行业有自己的落地页：痛点 → 方案 → 案例 → 客户 | 5 个行业页共用同一个模板 |
| 案例用「挑战 → 方案 → 结果」的结构 | Projects 页面可按行业筛选，每个案例都是这个结构 |
| 「询价」和「联系工程师」入口在全站各处保持一致 | 顶栏固定的 Request a quote 按钮、手机底部操作栏、分步询价表单 |
| 用数字、客户、认证、展会建立信任 | 首页的信任条、数字区、客户墙、展会公告 |
| 多语言 | 英文 / 印尼语双语，可一键切换 |

B2B 工业网站的研究结论：采购是多人决策；工程师会反复访问网站并转发给同事；完整的技术资料、结构化的案例和简短的询价表单最能促成询价。

## 3. 客户画像与网站对应

| 画像 | 关心什么 | 担心什么 | 网站上为 TA 准备的内容 |
| --- | --- | --- | --- |
| **工厂 / 工程经理**（制药、快消大厂） | 扩产、新产线、合规、设备稼动率 | 供应商交付不了、售后跟不上 | 行业页、案例、项目方法论、客户墙、和工程师沟通的入口 |
| **工艺 / 项目工程师** | 规格参数、布局、和现有设备的衔接 | 买到的设备和需求不符 | 设备目录和规格、3D 设计能力、出厂前和客户一起试机、可直接提交需求文件（URS） |
| **采购** | 供应商资质、交期、质保、付款和交货条款 | 选错供应商要担责 | 公司信息、1 年质保、交期说明、常见问题、询价表单 |
| **维修 / 设备经理** | 停机抢修、备件、老设备改造 | 响应慢，找不到人 | 服务页、WhatsApp 一键报修、改造能力、服务覆盖范围 |
| **汽车零部件生产工程师** | 节拍时间、检测、快速换模、防错 | 非标设备做不出来或做不稳 | 汽车行业页、非标设备案例（快速换模、无动力输送、检测工站） |
| **成长型中小企业主**（食品、草本） | 第一条自动化产线 | 不懂设备，怕买错 | 「买设备前要确认的 5 件事」、标准设备目录、免费咨询入口 |

**按访问意图分流**：首屏直接提供 4 个入口：新建生产线 / 自动化改造（非标设备） / 购买标准设备 / 维修、改造与备件。访客可以一步进入和自己相关的内容。

## 5. 设计原则

- **企业级、克制、可信**：对标头部企业的视觉语言，深海军蓝作为主色，Logo 的橙红渐变只用在行动按钮和重点强调上。
- **字体**：Plus Jakarta Sans，这是为雅加达城市品牌设计的字体，兼顾专业感和本地属性。
- **图片统一处理**：现有项目照片的分辨率和色调参差不齐，统一用海军蓝叠加和裁切来处理，保持整体质感。
- **任务优先**：每屏都有明确的下一步；手机底部固定「电话 / WhatsApp / 询价」三个按钮，方便在工厂现场的工程师。
- **证据优先**：所有数字和说法都能追溯到公司资料，不编造指标。
